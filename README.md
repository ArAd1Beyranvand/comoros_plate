# comoros_plate

Comoros's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the black single-row `1284 A 73` plate and the square two-row plate with the crescent and four stars, silver on black, with their theme, alphabets and an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:comoros_plate/comoros_plate.dart';

PlateCanvas(
  spec: ComorosPlates.standard,
  theme: ComorosThemes.standard,
  validator: const ComorosPlateValidator(),
  autoValidate: true,
);
```
